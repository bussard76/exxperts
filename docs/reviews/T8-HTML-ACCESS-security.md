# T8-HTML-ACCESS security architecture spec review

Verdict: level-3
Spec: GitHub issue #8, read 2026-11-07; branch tip reviewed: 9ebc303b0415368db96d69a236f17a987402abc5
Level: 3, raised from 2. Running untrusted workspace scripts changes the preview trust and data-flow contract; ADR-0003 explicitly does not approve a sandbox relaxation. The reported self-navigation can carry document content to a real external system, contrary to the dated “Allow scripts, no network” decision.
Decision: Needs Sascha. No accepted ADR authorizes this relaxation or decides the navigation disclosure tradeoff. The issue explicitly reserves this decision. This review does not authorize implementation or write an ADR; the task limits the only writable file to this report.

## Needs Sascha

The dated decision is “Allow scripts, no network”; the known self-navigation exception means the delivered behavior does not satisfy it. Options: (A) disable scripts until an enforceable no-network design is available; (B) allow scripts with the disclosed self-navigation/exfiltration risk and explicitly revise the product promise; (C) defer HTML preview. Recommend A as the smallest way to preserve the recorded privacy constraint while retaining a preview, subject to Sascha's decision and an accepted ADR defining the resulting contract. A sandboxed frame also limits top navigation and popups, but it cannot prevent navigation of itself; do not represent CSP alone as a complete network fence.

## Prefactoring

None required before the decision. Keep existing room policy and remote route enforcement seams; if a snapshot fix is chosen, reuse their existing bounded-file identity pattern without adding a new public module.
