## Prefactoring

None is justified before the decision. Keep the existing route, worker and UI seams where they can enforce the chosen policy; do not add a new abstraction solely for this review.

## Findings

1. **Level 3 — scripted HTML and navigation:** The issue's “no network” requirement conflicts with its acknowledged ability to navigate the frame to an external address carrying file content. ADR-0003 states that it approves no sandbox relaxation; the original T4 review required inert Word HTML and `sandbox=""`. Options for Sascha: (A) permit scripts with the disclosed navigation/exfiltration risk and describe the actual limitation; (B) disable scripts to retain the stricter isolation; (C) defer HTML until an enforceable isolation design is specified and reviewed. Recommend C if the no-network promise must be maintained, otherwise A only with explicit informed acceptance and a precisely scoped ADR amendment. Do not claim that the current CSP blocks every network request.
2. **Level 3 — host-open scope:** ADR-0003 authorizes only agreed preview types, and names extension reconciliation as a spec decision. Opening HTML invokes an external application outside the preview sandbox; the prior script decision does not expressly authorize that action or its effects. Include the two extensions and their host-open consequences in the Sascha decision, or remove them from the action pending approval.
3. **Design-relevant specification gaps:** Once the decision is recorded, fix exact GET response and `frame=1` behavior, resource and error states, identity/revalidation rules, cross-worker ownership and dependencies, and an end-to-end real producer/consumer acceptance test. A readiness response and later frame request can encounter different file or authorization states; the spec must say what users see on the second request's failure without leaking host details. Specify current source formats (`schemaVersion: 1`, `kind: "html"`, `html`, `notices`) or an approved replacement, rather than leaving parallel workers to invent them.

Tests were not run: this is a pre-build, read-only architecture review. No product code was changed.
