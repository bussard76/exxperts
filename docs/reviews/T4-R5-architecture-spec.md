## Findings and binding precision

No design-relevant blocker remains in the reviewed specification. Carry all R5 contracts, P1–P5, B1–B7, O1–O4, K1 and H1 into the build dispatch; these are obligations, not results of this review.

- **Version precedence:** the earlier package review's table and the earlier Controller package decision still literally specify jsdom 29.1.1. Those historical instructions conflict with the later explicit Controller compatibility decision and are superseded only for jsdom: use exact 26.1.0 at root and web-server, with exact docx-preview 0.4.1. R5's operative package table, Word contract, P3 and binding reconciliation consistently say 26.1.0; the other occurrences of 29.1.1 describe the old approval or current base, not authorization for the new consumer. Preserve all other package conditions. Do not silently change Node `>=20.6.0`, add an override or retain 29.1.1 for Word.
- **Existing consumers:** the current `fetch_url` lazily requires jsdom, parses with the source URL and passes a cloned document to Readability; `bundle-server.mjs` already ships jsdom as an external. Run its real extraction smoke, installed/pruned resolution and network-policy checks, the named existing jsdom suites and typechecks, doctor and packaging checks. Preserve loud missing-package failure and dynamic closure; do not duplicate jsdom in `FILE_PACKAGES`. Word probes do not prove these consumers work.
- **Sheet and resource precision:** every accepted sheet, including macro/chart sheets, must remain reachable or the whole document fail; a chart-decoration omission cannot hide a lost sheet. The selected owned extractor/decoder replaces the older SheetJS CFB and workbook-value instructions. Charge actual work and allocation before operations, including replays, references, output and SSF; prove reachable exact/one-over limits and the stated invariants for physically dominated limits. Timeouts, heap caps and post-allocation checks are not substitutes. Normative BIFF/CFB compatibility, formatter bounds and actual implementation correspondence remain test-first proof, not a new pre-build approval.
- **Actual package closure:** regenerate and review the final lock, preserve the 23 Linux optional `libc` fields where feasible or prove target selection and loading on supported glibc/musl. Verify installed and pruned artifacts, exact child/package resolution, missing/wrong assets, all nested/native dependencies, notices including isarray, saxes, JSZip and pako, and the 2,500-file ceiling. Audit the actual graph including non-registry SheetJS and the recorded nested uuid advisory, tmp and unzipper; candidate inventory and audit do not establish the release closure. Apply only the approved coverage-preserving `tsx` correction to the stale Koffi test.
- **Node and probe limits:** PDF metadata excludes some versions admitted by the unchanged root engine, including portions of the advertised range; assess actual installed preview and closure on supported Node versions and vendored 24.22.1 before compatibility claims or release, and escalate an observed incompatibility. The reported invented DOM probes and Controller reruns are narrow observations, not independent reproduction in this review, browser fidelity, complete network isolation or installed-product proof.
