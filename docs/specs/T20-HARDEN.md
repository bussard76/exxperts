# T20-HARDEN — current-main detached document contract

Status: revised **author draft**, 2026-11-11; awaiting a fresh different Architect's spec review. This author is the Analyst, not that reviewer. No spec-pass, build authorization, product/test/native/browser pass or support claim is supplied.

## Architecture impact

**Level 3**, accepted architecture A under [ADR-0009](../adr/0009-detached-document-window.md): one chat-owned document session, one portal host, native close/placement adapter in apps/desktop. Apps/web-ui owns volatile session, host transfer, event binding and correlated action arbitration; apps/desktop owns synchronous native prevention, trusted child registration and accessible child bounds. Existing server workspace/preview/Markdown/OS-open policy remains authoritative and unchanged; C7 reuses the contained one-shot frame delivery at the existing HTML frame entry without a new route or privilege. Accepted ADR-0002/0003/0004/0008 remain binding. No new public package export, dependency, route, durable store, backend, second App/WebSocket/editor/save pipeline or independent child lifetime is authorized.

## Controller compatibility clarification, 2026-11-11

C1 owner/request UUIDv4 allocation uses the actual owner realm's `crypto.randomUUID()` when callable, or that realm's `crypto.getRandomValues` for 16 bytes with the required UUIDv4 masks and canonical formatting only when `randomUUID` is unavailable. Missing or throwing cryptography fails closed; C5 shell-originated producers remain unchanged. The independently reviewed narrow correction is [T20-C1-COMPAT](../reviews/T20-C1-COMPAT-architecture-spec.md); it changes neither ADR-0009 nor the accepted product decisions.

## Frozen contract and lifecycle acceptance

The single normative field/result/ordering register is [contracts.md](../../design/t20-detach-window/contracts.md), **author freeze v1, 2026-11-11**, C1–C8. It fixes producer/consumer files; complete identity/generations; retained source/baseline/revision/RAW/conflict/permissions/pending-unknown writes; guarded transfer; prepare/refuse/allow/abort/abort-ack/commit/child-closed/completed; private native transport and registration; source/units/storage/visibility of child bounds; actual host documents/windows/events/focus/overlays; real opaque-frame source checking and retained snapshots; path routing/drag. Internal types are private implementation contracts, not new public package exports. Unknown/stale/busy/invalid/timeout never implies allow, discard, destruction or new writer authority.

Normal main ×/Cmd+W maps to guarded hide after child-closed; normal Quit/Cmd+Q guards before server shutdown; updater-ready guards before updaterQuitting/server stop/install; normal menu/accelerator reload guards before renderer teardown. Hide/minimize alone keeps the session. Child ×/Return moves without save/discard. In browser, only the explicitly decided async-guard-bypass close/reload paths are Q5=B exceptions; in-app room/conversation leave is still guarded. Current desktop smoke's app.exit cannot prove normal native quit. Room/conversation changes close current child before replacing context and require explicit Detach in the next context. No file selection is needed for Detach; popup/bootstrap/style failure leaves the original attached session authoritative.

The host state diagram and correlated lifecycle sequence are in [logic](../../design/t20-detach-window/logic.md). Native binding is a trusted-window control adapter with no arbitrary window/OS API, no credential/draft in messages or bounds, and no additional grant. Local/paired/read-only/security controls remain enforced by existing routes and opaque-frame CSP/sandbox.
